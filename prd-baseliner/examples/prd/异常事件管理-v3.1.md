# 异常事件管理 PRD（v3.1）

> ⚠️ 这是用于验证 prd-baseliner M2 的**占位 fixture**，非真实历史 PRD。
> v3.1 相对 v3.0 有意改动「流程」与「问题来源」两节，用于演示文档历史漂移检测。

## 1. 需求背景

异常事件是"异常与风险管理"环节的核心概念，集中体现管理标准与各上报渠道的风控策略。

## 2. 异常事件全生命周期（流程）

A程序接收状态变更记录后生成问题；问题判定后生成新异常事件或合并进已有异常事件；
异常事件生成排查处理单，工单流转：指派 → 执行 → 审批，审批不通过则回到执行环节；
工单结束后做异常事件关闭判断，不满足则更新问题回到生成异常事件。

## 3. 问题来源（枚举）

问题来源共 **10 种**：计划巡检、临时维修、IOT报警、异常上报、用户报事、人工修改、数据监控系统。

## 4. 异常事件对象（数据）

异常事件对象包含属性：名称、持续时长、事件等级、始发时间、当前影响、严重程度。
其中"名称"为实时拼接，"持续时长"为当前时间减始发时间。

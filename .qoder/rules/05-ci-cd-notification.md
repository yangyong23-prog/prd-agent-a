# Forgejo Actions 与钉钉通知

当前仓库暂未内置 Forgejo Actions、K8S 部署文件或钉钉通知脚本。以下内容是后续接入 sandbox CI/CD 时的目标规则，不代表当前仓库已具备这些能力。

接入后，Push 到部署分支可触发流水线：

1. 构建开始通知；
2. 构建失败通知；
3. 构建成功通知；
4. 镜像推送；
5. 部署开始通知；
6. 部署失败通知；
7. 部署成功通知；
8. 冒烟测试失败通知；
9. 最终上线成功通知。

失败通知必须包含失败阶段、日志链接、分支、Commit、Build ID、镜像 Tag。
成功通知必须包含访问地址、版本信息和自测入口。

# 老产品接口调用规则

当新功能需要使用老产品能力时：

1. 必须先读取 `docs/product-apis/allowed-api-list.md`。
2. 只能调用文档中列出的老产品测试环境接口。
3. 禁止调用生产环境接口。
4. 禁止直接读取老产品数据库。
5. 禁止猜测未文档化接口路径、参数或响应字段。
6. 如果接口不足，必须输出 `templates/product-api-request-template.md` 格式的接口需求申请，交平台/研发新增，**不得自行往白名单里添加条目**。
7. 白名单由平台维护；CI 会对 `allowed-api-list.md` 做基线校验，本地擅自新增会导致流水线失败。
8. 老产品接口地址只能来自环境变量 `PRODUCT_API_BASE_URL`，不得在源码中硬编码 URL。
9. 研发 Review 交接说明中必须列出所有老产品接口调用。

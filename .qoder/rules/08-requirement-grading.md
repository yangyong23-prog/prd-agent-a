# 需求分级 L1/L2/L3/L4

每个需求在出 Spec 前必须先分级，用于设定审查与自测的力度。

- L1 展示类：只读老产品测试接口或读当前项目自有表，纯页面展示，无写库。自测重点：页面与空数据。
- L2 数据加工类：通过 Prisma 调整当前项目自有表、写入测试数据，组合多个白名单接口。自测重点：数据库影响范围、接口失败处理。
- L3 流程类：多步骤交互、状态流转、依赖多个老产品测试接口。自测重点：状态正确性、并发与异常路径、回滚。
- L4 受限/超界类：需要当前项目未实现的部署能力、需要未登记老产品接口、或触及老产品数据库。**不直接实现**：输出接口需求申请或记录，交回研发，不要变通绕过。

分级原则：拿不准就往高一级靠；出现 L4 信号（要未登记接口、要连老产品库、要当前仓库不存在的部署/日志能力）立即停下并上报。
